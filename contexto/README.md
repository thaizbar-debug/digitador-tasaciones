# contexto/

Información de dominio que el skill `digitador` necesita para hacer buenas transcripciones. Cargá acá todo lo que no está en el código pero sí en la cabeza del equipo.

## Archivos

- `glosario.md` — Términos técnicos (partida arancelaria, PU, valor comercial, etc.).
- `proceso.md` — Cómo trabajan tasador y digitadora, dónde se pasa la información.
- `ejemplos/` — (opcional) Ejemplos reales anonimizados de informes ya digitados, útiles para calibrar el estilo.

## Cómo mantenerlo

Cuando encuentres una regla implícita (por ejemplo: "en BCP el valor comercial siempre se expresa en soles con dos decimales") anótala acá. El skill lee esta carpeta antes de generar cualquier informe.
