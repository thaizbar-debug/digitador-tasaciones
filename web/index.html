Sube la documentación que envió el tasador y descarga el paquete listo para que el skill lo procese.

El HTML carga la plantilla oficial del banco, transfiere los datos del borrador celda por celda respetando las fórmulas oficiales, y descarga un ZIP con el informe final ya rellenado en output/informe-<trabajo>-<banco>.xlsx, junto con revisar.md y anexo-fotografico.md.

Informe generado. Próximos pasos:

  1. Descomprime el ZIP donde quieras (por ejemplo en la carpeta entregas/ del proyecto).
  2. Abre output/informe-<trabajo>-<banco>.xlsx y verifica los datos.
  3. Pega las fotos en la hoja FOTO (o equivalente).
  4. Revisa output/revisar.md para el checklist manual antes de enviar al cliente.
